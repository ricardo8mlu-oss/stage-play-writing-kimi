# 话剧编创 Skill（Kimi 版）

[下载完整 ZIP 包](stage-play-writing-kimi.zip)。解压后按 [KIMI-INSTALL.txt](stage-play-writing-kimi/KIMI-INSTALL.txt) 安装。

- Kimi Code：将 `stage-play-writing-kimi` 文件夹放入技能目录，在新会话中调用 `/skill:stage-play-writing-kimi`。
- Kimi 网页版 Agent：使用包内的 `Kimi-Agent-话剧编创导入稿.docx` 通过“Office 文档转技能”导入。
